# Description of the code
We decided to divide our code into four branches: main, dashboard, data-reading, and thingSpeak. 


## Branch 1: Main
This branch is the full code: The code to read the Arduino data, the code to craete the GUI dashboard, and the code to create the ThingSpeak graphs.


## Branch 2: Dashboard
This branch only contains the code to create the dashboard.


## Branch 3: Data-reading
This branch only collects the data from the Arduino.


## Branch 4: thingSpeak  
This branch only contains the code to create the thingSpeak graphs.
